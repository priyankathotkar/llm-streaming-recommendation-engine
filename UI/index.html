About CineAI

An emotion-aware AI recommendation engine built with modern machine learning.

Project Overview

CineAI is an experimental AI-powered movie recommendation system that goes beyond simple genre filtering. It detects your emotional state and recommends films specifically chosen to counter or complement your mood — making you feel better, not just validated.

How It Works

  • User input can come from text queries, uploaded images, or real-time camera detection.
  • Facial emotion detection runs using HuggingFace transformer models.
  • Detected emotion is mapped to opposite-mood genres (sad → comedy, angry → calm).
  • Sentence Transformer embeddings + FAISS search across 62,000 movies.
  • Ollama Llama3 generates a personalised, mood-aware explanation.

Key Technologies

  • FastAPI backend · Uvicorn server
  • FAISS vector similarity search · all-MiniLM-L6-v2 embeddings
  • MediaPipe Face Mesh · HuggingFace emotion classification
  • Ollama Llama3 · LightGBM drift detection
  • TMDB API for poster retrieval · Chart.js for visualisation

Future Improvements

Collaborative filtering, reinforcement learning from user feedback, persistent user profiles, streaming service integration, and multi-modal embeddings combining poster images with text.
